## 全コース共通ログインとクイズ進捗の端末間同期

### 実施内容
- neuve の全コースで共通のログイン（Google・メールリンク）とマイページ（ポータル https://neuve.com/learn/ ）を使えるようにした
- 章末クイズの結果（localStorage の `github-guide-quiz-<章ID>`）を、ログイン中は Firestore と双方向に同期する。別の端末でログインすると、クイズの回答・スコアがそのまま復元される

### 変更
- `docs/src/components/Head.astro`: 共通キット（`https://neuve.com/learn/kit/neuve-learn.js`）を読み込み、`mirrorLocalStorage` でクイズ結果を同期
- `docs/src/components/SocialIcons.astro`（新規）と `docs/astro.config.mjs`: ヘッダー右側にログイン状態（`<neuve-auth>`）を表示
- `docs/src/components/Progress.tsx`: 章の一覧を export し、別の端末の進捗が書き戻されたとき（`neuve-learn:synced`）に表示を更新
- `docs/src/pages/course.json.ts`（新規）: ポータルのマイページが読むレッスン一覧（50 章）

### 検証
- `npm run build` 成功（53 ページ、`dist/course.json` に 50 章）
- Firebase エミュレーター（Auth・Firestore）とブラウザで、次の流れを確認
  - 未ログインで解いたクイズが、ログイン時にサーバーへ上がる
  - ログイン中に解いたクイズが、その場でサーバーへ反映される
  - 別のブラウザでログインすると、クイズ結果が localStorage に復元され、学習進捗ページが「2/50章」に更新される
  - ポータルのマイページに「2 / 50 完了」と次の章が表示される

### 後方互換性
- ログインしなければ従来どおり localStorage だけで動く。既存のクイズ結果は消さない
- 共通キットが読めない場合も、ヘッダーのログイン表示が出ないだけでサイトは動く
